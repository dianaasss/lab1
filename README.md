# Лабораторная работа №1

## Тема
Элементы объектно-ориентированного программирования в языке Python

## Цель работы  
Приобретение навыков по работе с классами и объектами при написании программ.

## Задание 1
Реализовать класс Time с полями:
- first - целое положительное число, часы
- second - целое положительное число, минуты

**Методы:**
- __init__ - инициализация с проверкой корректности
- read() - ввод с клавиатуры  
- display() - вывод на экран
- minutes() - приведение времени в минуты

Реализовать внешнюю функцию make_Time()

## Задание 2
Реализовать класс Account, представляющий банковский счет.

**Поля:**
- Фамилия владельца
- Номер счета
- Процент начисления
- Сумма в рублях

**Операции:**
- Смена владельца
- Снятие/пополнение средств
- Начисление процентов
- Конвертация в доллары/евро
- Получение суммы прописью
